# Linked List From Scratch

A Python linked list built from scratch while learning Grokking Algorithms.

## Files
- `linked_list.py`: the Node and LinkedList classes
- `LinkedList_main.py`: a demo that runs every method

## Methods
- `insert_at_head(data)`: adds an item to the front
- `insert_at_end(data)`: adds an item to the back
- `traverse()`: prints the whole list
- `delete(data)`: removes the first matching item
- `search(data)`: finds the position of an item

## Run it
```
python LinkedList_main.py
```
